# Portfólio Martha

Site estático em HTML, CSS e JavaScript, com Vite para desenvolvimento e build.

```sh
npm install
npm run dev -- --host 127.0.0.1
npm run build
npm run preview
```

Edite textos e links em `index.html`, detalhes dos projetos em `app.js` e estilos em `style.css`. A foto fica em `public/assets/perfil.jpg`. Fontes são servidas localmente.

Os projetos são referências demonstrativas de Radilson Gomes, creditadas na interface. Substitua por trabalhos reais antes de publicar. Nome e biografia de Martha são provisórios. ServiceBell possui vídeo público de demonstração servido localmente, ativado por hover/foco. Os demais cards usam animação de imagem. Para incorporar vídeos reais dos seus trabalhos, forneça os arquivos correspondentes.

O vídeo original enviado é apenas referência, não é incorporado ao site. `qa/video-contact.jpg` contém frames extraídos para análise da sequência de entrada.
